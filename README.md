# The Path I Could Never Reach

A responsive, dark-and-gold educational website about learning useful skills, entrepreneurship, financial literacy, technology, and long-term wealth building.

## Files

- `index.html` — page structure and content
- `style.css` — responsive design and visual styling
- `script.js` — mobile navigation, search, and category filters

## Preview locally

Open `index.html` in a web browser.

## Publish with GitHub Pages

1. Create a **public** repository on GitHub named `the-path-i-could-never-reach`.
2. Upload all three website files (`index.html`, `style.css`, `script.js`) to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait a few minutes. GitHub will show your website address in the Pages section.

## Customize

Edit the text in `index.html`, colors near the top of `style.css`, and interactions in `script.js`.

## Important note

This is an educational website template, not a promise of wealth or financial advice. Investing and business involve risk; visitors should research carefully and follow local laws.
